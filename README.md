# Trabajos académicos

Este repositorio es mi almacén de algunos trabajos de la universidad: tareas, proyectos, ejercicios y algunos apuntes que estoy guardando durante la carrera. Claramente, no es un portafolio, es un lugar donde comencé a reservar para tener todo ordenado y poder volver a encontrarlo. Esta manera de organización nació usando de forma recurrente LaTeX por mera iniciativa.
